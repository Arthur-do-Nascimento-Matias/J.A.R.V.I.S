# J.A.R.V.I.S
Is an AI based on the famous one from Marvel's Iron Man. It is able to answer questions about any theme and also play music. The questions can be submited by text or by voice.

# Make sure you have installed:
-Python
-ollama
-langchain
-yt_dlp
-flask
-groq
-unidecode

# how to run:
On the terminal run: 
python main.py and npm run dev

# this is on current updates so be aware that it may include bugs
